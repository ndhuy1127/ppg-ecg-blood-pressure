# Firmware

- **app/**: logic ứng dụng.
- **drivers/**: driver thiết bị ngoại vi và cảm biến.
- **boards/**: cấu hình theo board.
- **include/**: header dùng chung.
- **tests/**: kiểm thử firmware.

Firmware phải ghi rõ board, toolchain và cách build khi mã nguồn đầu tiên được
thêm. Không commit khóa hoặc thông tin kết nối thật.
